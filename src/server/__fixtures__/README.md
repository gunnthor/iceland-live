# Camera frame fixtures

Two consecutive real frames from Vegagerðin's Ártúnsbrekka camera, sixty
seconds apart, kept so the frame store's change detection can be tested
against a genuine picture rather than a synthetic one. A JPEG cannot be
written here without an encoder, and a synthetic file would not exercise the
Huffman path these cameras actually produce.

They differ by about 1.75% of blocks — a vehicle moving — which is above the
store's default threshold of 0.25% and below a raised one, so the same pair
demonstrates both outcomes.

Based on information provided by the Icelandic Road and Coastal Administration
(IRCA). Iceland Live is not affiliated with IRCA.
